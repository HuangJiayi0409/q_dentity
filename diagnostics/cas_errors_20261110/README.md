# CAS 历史测试报错与诊断记录

整理日期：2026-11-10。测试记录主要来自 2026-10-21，未重新运行测试。

本目录保存历史运行证据，不能视为当前版本的未修复缺陷列表。测试中的“不支持”“未找到证书”和“超时”也不等同于程序错误或数学命题错误。

## 内容

- `two_method_diagnosis/`：9 道望远镜法、30 道递推法样本的逐题诊断，39 份原始 JSON 报告。`index.json` 提供包内报告路径。
- `train_all_methods_20261021_24/`：346 题 × 12 方法的逐任务记录、汇总及报告。并非每项失败都含异常堆栈。
- `certificate_exits_20261021/`：Lean 原始诊断示例与后续证书出口修复报告。
- `recurrence_closure_20261021/`：后续四题复测，区分 Lean 未闭合、超时及局部通量表示问题。
- `math_library_single_trial_20261021/`：对象导出改善后的单题对照，导出成功仍不代表整题已证明。

## 主要失败类型

1. 表达式导出或前端结构不支持，如任意函数应用、pochListInt 等。
2. 移位正规化失败，如 `representation_gap: nonlinear shift exponent` 和 `not a single-base rational shift`。
3. 证书已构造，但 Lean 重建留下 `unsolved goals`。
4. 符号计算或验证超时、复杂度预算耗尽。
5. 原域条件问题：部分局部通量在 q=0 时不成立；这是证书表示的问题，不是原恒等式的反例。
