# FQI-SRC-FINE-25.shell · 固定最大部件与 rank 的有限生成多项式

在以下来源条件及记号约定下，证明所列关系。

$$
\sum_{\substack{\lambda_1=L\\\lambda_1-\ell(\lambda)=r}}q^{|\lambda|}=q^{2L-r-1}\begin{bmatrix}2L-r-2\\L-1\end{bmatrix}_q.
$$

代表来源：`FINE-25.shell`。
