目标是将原题整理成可共享的数学表示，并为实际发生的整理提供等价证据。输出不包含方法选择、分类标签或十二种方法各自的请求格式。预处理保持独立；方法侧通过显式 `--preprocess` 消费同一份标准目标。历史批测结果保留，不覆盖旧输出。

## 数据流程

```text
当前 Train 原声明 + 原始共享定义
    ↓ 原文、清单及依赖快照
Lean 类型化表达式（保留完整参数、实例、绑定、假设）
    ↓ 明确规则清单；条件不满足则保留
原表示 + 一个整理后的表示 + 每步等价证据
    ↓ 在原题上下文中独立回放、内核检查、公理审计
公共 DAG / 定义表 / 转换记录 / 可核查的来源
```

1. **统一加载**：`source.py` 直接读取当前 `benchmark/splits/train.jsonl`，不使用旧三类方法的准入名单或家族标签。检查源文件哈希并保存递归共享依赖；不加载 Test、旧证明结果或目标定理模块。当前前端只接受现有的一文件一条 `theorem`、一个独立 `sorry` 证明位置的源码形状；其他形状明确拒绝，不声称接受任意 Lean 文件。
2. **公共表示**：`representation.py` 将 Lean 表达式编码为结构共享 DAG。变量按 De Bruijn 索引绑定，原变量名作为展示信息保留；完整保留类型、宇宙、隐式参数、类型类实例、量词、局部定义与未知常量。排除 elaborator 的内部递归声明占位符，它不是原题假设，也不能用于消去变换条件。常量仍使用限定名，不用打印文本猜测数学语义。涉及的 `FiniteQBenchmark` 定义另存声明表及其定义体，仅对明确白名单中的非递归数学包装定义展开进标准目标。
3. **受控整理**：`Rules.lean` 与 `Export.lean` 指定规则及方向。保留原式，只生成一个整理视图；不遍历所有等价形式，不以启发式 `simplify` 的输出充当唯一数学标准形。
4. **转换证据**：每步以共享节点引用保存完整前后目标和 `∀ 原上下文, 原目标 = 新目标` 的证明项，另保存整条链的证明。后续 `run` 将在独立 Lean 调用中重新加载原题、回放证明项并审计公理。只有回放通过才发布 `standard.json`。

## 首版整理范围

| 对象 | 规则与限制 |
| --- | --- |
| 自然数半开区间求和、乘积 | `Ico a b` 转为 `range (b-a)`，原项改为 `f (a+j)`；保留自然数截断减法，空区间也适用 |
| 相同有限域上的两个和 | 合并为逐项相加；仅匹配同一有限域，不猜测不同区间之间的边界关系 |
| 和中的指标无关因子 | 从左侧或右侧提出，保持乘法顺序，不暗加交换律 |
| q-Pochhammer | 零长度化简、参数列表的空表/构造子拆分；不将一般长度展开为逐项表达式 |
| 基础代数 | 明确列出的零、一、零次幂、一次幂及空和空积规则 |
| 带条件约化 | `a/a=1` 只在已有上下文能提供所需非零命题时使用；未知条件不添作新假设 |
| 其他对象 | 保留完整结构与定义引用；不因当前规则不认识而丢失原题 |

规则至多遍历三轮，并记录 `round_limit_reached`。触及上限仍可有正确的有限转换链，但不能声称已经达到不动点或完备标准形。基础定义性约化、同余与绑定结构处理由 Lean simplifier 完成；不加载全局 simp 规则集，不调用 `ring`、`field_simp`、求和算法或分类器。

当前不做：一般整数区间移位、任意不同边界的和同步、变量区间拆分、未经证明的自然数/整数转换、Gaussian 多项式与商表示的强制互换、负长度 Pochhammer 展开、无条件消去分母、交换因子排序、ΠΣ 代数独立基构造，以及求解器专属变换。这些对象仍能以原始类型化结构存在；“保留”不等于已经整理为某个求解器可接受的形式。

## 命令接口

从项目根目录运行，`--identity` 必须是当前 Train 的精确 ID，输出目录必须尚不存在。下列路径是使用示例，实际验收目录另存于 `generated/preprocessing_connection_20261018/`。

只保存原题、依赖和规则源码快照，不启动 Lean：

```bash
python3 -m finite_product_framework.preprocessing prepare \
  --identity FQI-BAILEY-INVERSION \
  --output /tmp/preprocess-bailey-prepared
```

完整生成与回放：

```bash
python3 -m finite_product_framework.preprocessing run \
  --identity FQI-BAILEY-INVERSION \
  --output /tmp/preprocess-bailey-run \
  --timeout 600
```

`run` 创建自己的新快照，不复用 `prepare` 的输出目录；总预算包含依赖编译。只使用本地指定 Lean 工具链和 Mathlib 缓存，不自动安装依赖。Benchmark 共享模块及本模块的 Lean 文件在独立目录编译，不引用旧批测产生的目标证明 `.olean`。

## 输出契约

| 文件 | 含义 |
| --- | --- |
| `original.lean` | 原题原文，保留原始待证明位置 |
| `request.json` | 当前 Train 清单、源文件、依赖、实现版本哈希和编译顺序 |
| `src/` | 共享定义、规则、导出及回放源码快照 |
| `bundle.json` | Lean 原始表达式编码、定义表、每步及总等价证明项 |
| `candidate.json` | 已生成但未完成独立回放的公共表示，状态始终为 `unverified_candidate` |
| `standard.json` | 仅在独立回放通过后生成；含原式/新式 DAG、上下文、定义表、转换记录和证据指纹 |
| `status.json` | 阶段、失败原因、耗时与日志索引；所有状态均为 `identity_proved=false` |
| `logs/` | Lean 原始 JSON 诊断，保留导出及回放的专用结束标记 |

状态为 `prepared_unverified`、`failed`、`verified_unchanged` 或 `verified_normalized`。这里的 **verified 只指整理前后等价**，并不表示原恒等式已经被证明。若仅生成候选或某步失败，不得将候选当成经过核验的标准输入。

`standard.json` 的 `nodes` 保存内核表达式构造子；`objects` 是常量头的便捷标签，允许部分应用，明确标记 `arity_not_inferred`，不把类型参数误当成数学操作数。`declarations` 保存原题涉及的项目定义及其类型，外部库常量依赖所记录的环境。公共 DAG 的结构哈希忽略变量展示名与表达式元数据，不判断数学等价。完整原名和证明项保留在 `bundle.json`。上下文展示字段 `type_in_full_context` 中，索引 0 对应上下文数组最后一个变量；权威绑定关系以闭合目标中的量词/let 为准。回放核对上下文数量、角色、绑定类别和类型；生成的展示名可能随 Lean 编译文件变化，不能作为语义标识。

目前只提供结构哈希与完整前后目标的对应，不提供逐字符 LaTeX 位置映射。未知项目符号用 `preserved_defined_object` 标注，这不是失败或数学不可证明。条件不足的规则直接跳过，当前不生成逐位置的“缺失条件”候选列表。

导出及回放 tactic 在完成等价证据检查后故意以专用错误结束，避免把原目标填成占位证明或误计原题成功。调度层只接受唯一对应结束标记，任何其他 Lean 错误均按失败处理。公理允许集合为 `propext`、`Classical.choice`、`Quot.sound`；禁止目标定理依赖和 `sorryAx`。证明核验负责等价性；规则标签用于追踪一次规则遍历，不代表证明项只引用该标签对应的单一定理。
