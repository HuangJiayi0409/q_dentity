## 预处理策略

默认视图为 `structured`：保留 `phi` 等数学对象和自然数闭区间 `Icc` 的结构，继续使用受控基础整理。`expanded` 视图保留 v2 的白名单定义展开、闭区间重排能力。两个视图都保留原声明，并分别生成、回放等价证据；缓存键明确区分视图。

用法：

```bash
python3 finite_product_framework/prove_recurrence.py --identity ID --preprocess
python3 finite_product_framework/prove_recurrence.py --identity ID --preprocess --preprocessing-view expanded
python3 -m finite_product_framework.preprocessing run --identity ID --output NEW_DIRECTORY --view expanded
```

当前视图选择是显式的，并未实现分类器，也没有自动逐个视图重试。每次调用仍受原总预算限制。不能把分别运行两个视图的额外预算隐藏为一次公平的同预算实验。

这是表示策略的修复：定义展开并非错误等式，但会绕过原方法识别 `phi` 的入口；`Icc` 重排也会绕过核变换的有限三角域入口。等价且更展开的形式，不保证更适合当前算法。
