# 预处理 v2（2026-10-19）

此次修改针对第二轮报告暴露的输出膨胀、重复预处理和定义包装遮蔽求和结构。仍是独立、方法无关的预处理模块；没有分类器、方法专属请求生成或全量批测。

## 已实现

- **紧凑证据**：Lean 在输出前将 JSON 容器按结构共享；Python 和 Lean 各自解码同一 `packet_version=2`，保持全部类型、绑定、隐式参数和证明项。公共 `standard.json` 使用 `finite-q-preprocess/2`，上下文、转换和关系中的表达式改为 DAG 引用。历史非压缩证据仍可解码，但完整旧规则策略不承诺跨版本回放。
- **统一缓存**：十二方法的共同 worker 在 `--preprocess` 下调用 `cached_run`。键包含当前 Train 源及依赖、预处理源码、Lean 可执行文件、工具链与库清单。进程锁确保同一键只构造一次；仅成功回放的结果原子发布。命中时复核全部缓存文件及当前源码；损坏直接拒绝，失败目录不成为缓存。等待计入预处理预算。默认在 `generated/preprocessing_cache_v2`，可用 `FINITEQ_PREPROCESS_CACHE` 指定目录。冷缓存和热缓存耗时不可直接比较。
- **类型化参数位置**：从 Lean 内核常量声明导出签名、绑定参数名、显式/隐式/实例标记。已知数学对象的视图依签名区分完整应用、部分应用和过度应用，保留所有实际参数；不再从末尾参数猜操作数。原有 De Bruijn 绑定和未知函数应用不丢失。签名在回放时核对。
- **受控展开**：白名单包含 `wellPoisedRaw`、`bibasicPhi`、`multibaseTerm`、`ultraspherical`、`littleJacobi`、`qRacah`、`askeyWilson`、`phi`、`phiTerm`、`fineA`。只对环境中存在的定义实施；原目标及定义表保留，每一步归入内核检查的等价链。所有方法通过已有 `preprocess_enter` 消费同一标准目标，实际读到展开后的结构。
- **区间与条件**：加入 Nat `Icc a b → range (b+1-a)` 求和/乘积整理，保留截断减法和空域。具体列表的 `map` 与 `length` 也按明确等式规则化简。非零条件仍仅由已有假设支持，不注入 `CharZero` 或其他假设。
- **通用关系**：导出已证明的 `poch_shift` 及完整类型，描述 `(a;q)_(n+1)` 的乘积递推；作为可用关系保留，不把所有 Pochhammer 强制展开，也不等于已经完成一般 ΠΣ 移位关系提取。

## 验证与解释范围

验收文件位于 `../generated/preprocessing_v2_20261019/validation.json`，原实现备份在该目录的 `baseline_sources/`。专项覆盖存储保真、并发复用、缓存篡改、有限区间含空域、条件缺失、定义展开、等价证据/上下文/签名/关系篡改，以及选定 Train 原题的实际方法接入。

预处理通过只表示原题与标准目标等价，不等于恒等式已被证明。没有启动 346×12 新一轮批测，也不据专项结果报告新的整体证明率。

## 明确仍有的边界

各方法的核心算法及旧解析器并未统一重写成直接消费公共 DAG 的求解器。共同入口消费标准 Lean 目标，公共签名和关系提供了后续直接读取的基础；未知函数、整数区间、复杂多重指标仍可能被方法拒绝。合取、蕴含和量词完整保留，但尚无跨子目标自动调度及整题证明组装。一般整数区间转换、任意嵌套和积的移位系统、代数独立基与方法覆盖扩张不属于本次已完成能力。未知条件不会静默放宽为假设。

共享缓存减少重复预处理及其重复证据存储；方法自身的独立构建目录仍会占用空间。这里没有声称消除了全工作流的所有磁盘开销。

- 30 项共享存储/缓存/接入/工作流 Python 回归、17 项 P1 回归、15 项 Lean 专项检查通过。
- `POCHHAMMER-RESIDUES` 经新入口完整证明并通过原题依赖审计；这是既有成功题的回归，不计新增证明。

- `GR2-3.10.14` 从 `bibasicPhi` / `List.length` 解析失败推进到 `analyzed`，但所测两条 Gosper 分支要求求和项不依赖外层参数，仍未证明。没有把这种算法适用范围限制当作预处理失败。
- 实际热缓存命中约 0.09 秒；这是单次观察，不是性能基准。
- 当前 346 道 Train 原题源码哈希全部与清单一致，没有读取 Test。

`evidence/` 保留源码、声明、证据包、证明文件和诊断；编译缓存未重复归档，原始报告中的 `/tmp` 路径保留运行来源，归档目录映射见验收文件。这些材料可供核查，但不能直接当作完整的已编译缓存目录。
