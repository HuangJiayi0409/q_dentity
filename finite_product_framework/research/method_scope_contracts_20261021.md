# 十二种符号证明方法的范围与契约 v1

日期：2026-10-21。性质：**范围设计与当前源码静态审查**，不是新算法实现、完备性证明或覆盖率报告。

本文件落实用户的要求：先按照数学结构界定每种方法接收什么、构造什么证书、在什么条件下完成证明，再按整个输入子类补齐求解流程。题号不参与范围定义，个别题目只可用于后续验收。现有十二入口保持不变，不恢复已删除的五核心原题流程。

## 1. “范围”需要分成三层

| 层次 | 回答的问题 | 本文件的用语 |
| --- | --- | --- |
| 数学对象与证明机制 | 什么结构允许采用这种证明思路？需要哪些假设？ | 数学范围 |
| 指定算法的计算域 | 算法接收什么有限表示？搜索哪个证书空间？何时能保证完成该计算问题？ | 算法范围与保证 |
| 当前完整证明入口 | 源公式能否转换、核心能否调用、证书能否回到原声明并通过 Lean？ | 当前实现范围 |

三者不能互相替代。例如“有限维矩阵可作精确运算”不等于“已能证明任意符号阶数 n 的矩阵恒等式”；“找到局部递推”不等于“已证明原有限和恒等式”。

本文中“入口可接收”只承诺进入指定计算流程。它不承诺输入恒等式为真，也不承诺存在该类证书。**完备性只能相对于明确的系数域、表达式类和证书空间陈述。** 有限预算搜索、固定模板搜索、完整代数子程序、原题证明成功须分别记录。

### 与用户所指 WZ 论文的关系

[WZ-LLM 原文](https://arxiv.org/html/2605.04472v1)第 3、4.1 节及附录 A、E 使用双变量普通超几何项 F(n,k) 和对 k 的单重求和：规范化后构造 WZ／创造性伸缩关系，再处理边界、初值、分母和分支。附录也讨论高阶递推。这支持“先规定表示与证书，再统一生成证明义务”的设计。

但论文的 WZ-covered 还含有“符号引擎实际能够产生证明骨架”的操作性判定；不能将其理解成对所有超几何输入的成功承诺，也不能从中推出项目已经具备多重、多基 q 求和算法。本文会把结构准入条件与构造结果分开。当地文件为 [2605.04472v1.pdf](../../2605.04472v1.pdf)。

## 2. 共同输入契约

未来每条方法应消费相同的、带语义证据的输入信息，再检查本方法特有条件。以下是**待落地的契约字段**，不是声称当前 IR 已全部提供。

| 字段 | 必须说明的内容 |
| --- | --- |
| 原声明 | 原目标、类型、量词、假设及源码绑定；不添加原题没有的假设 |
| 系数环境 | 交换环／域／非交换代数，特征，形式参数与允许特化值 |
| 外层参数 | 归纳指标、参数移动方式、自然数／整数类型 |
| 求和与乘积域 | 指标个数、顺序、上下界、有限性、零延拓、分段支撑 |
| 基 | 基的个数、相互关系、是否独立、是否为根单位；q 和 q² 不能直接登记成两个独立基 |
| 表达式语法 | 支持的原子及其定义、长度与指数类型、移位规则；未知函数不能仅凭名字接收 |
| 目标结构 | 求值、两和变换、序列关系、系数、乘积、算子、核、谱或行列式 |
| 证明运输 | 原式到标准表示的等式、支撑与非零条件、参数特化的合法性 |
| 资源参数 | 阶数、次数、维数、模板深度和时间；每项说明是数学限制还是实现预算 |

共同成功条件是：完整原声明通过 Lean，依赖和公理审核通过，无剩余义务，证书绑定本次输入。现行接收实现见 [workflow/contracts.py](../workflow/contracts.py)。CAS 精确等式、数值抽样、局部见证都不能单独计作原题成功。

### 建议统一的结果含义

下面是接口设计，不是本轮修改过的运行状态名：

- `outside_declared_domain`：已知违反本后端的输入条件。
- `eligibility_unknown`：当前无法认证准入条件；与已证不适用区分。
- `representation_gap`：数学子类已声明，源表示或语义桥尚未实现。
- `search_exhausted`：指定的有限搜索空间已用尽；不表示更大空间无证书。
- `no_certificate_in_declared_class`：只有完整的该类判定算法结束后才能使用，并附域与证书类。
- `resource_exhausted`：时间或其他预算耗尽。
- `certificate_constructed`：局部符号构造成功，原题义务仍可能未闭合。
- `proof_obligation_open`：指出表示、边界、初值、奇异点或 Lean 重建中的具体缺口。
- `proved`：完整原题通过统一接收。

这些失败状态都不意味着恒等式为假。判伪若另行实现，必须有原域内的有效反例或独立证明。

## 4. 各方法的准入、保证和改进单位

### 4.1 `telescoping`：有限差分求值

**数学范围。** 目标含可认证的有限求和域。单指标时，在指定函数域内寻找 G，使差分等于被加数；双边或多重域也可使用差分思想，但需要各自的支撑与通量算法。本方法不以“结果可写成乘积”为准入条件。

**可执行子类。** 单基 q-Gosper 接收可表示的 q-超几何项，形式移位商 f(k+1)/f(k) 在所声明的有理函数域中。多个基要给出对应移位自同构及基间关系。原项为零、支撑端点和特化时的分母须另行保留，不能把形式比值当成全域定义。

**算法与保证。** 规范化移位商，推导分母和次数界，求有理 R，使 V·σ(R)−R=1，再取 G=Rf。完整 q-Gosper 子程序的“无解”仅限其超几何原函数／有理乘子类。多个方向的差分不能由一维 Gosper 自动推出完备性。多重创造性伸缩的项目归属见递推类，不增加第十三方法。

**原题出口。** 检查 G 的实际表达式和局部差分；计算两端及分段接缝；证明其等于原右端。端点可以非零，不要求所有边界都消失。

**当前实现。** [general_summation.py](../p1/general_summation.py) 的通用入口要求至少一边为完整单指标和，支持共享外层自然指标的 `range(a*n+b)`，a、b 为非负整数字面量，表达式受 IR 限制；旧 Gaussian 路径仍存在。[双基契约](../p1/branches/bibasic_gosper.md)的完整出口进一步限 `range(n+1)`、被加数与 n 无关、两个独立基、指定 Pochhammer／整次幂／几何权重表示。最多 8 个分子原子是表示搜索预算，不是双基数学上限。

**排除与下一改进单位。** 不将“任意多基”“任意嵌套求和”“任意分段支撑”列为现有承诺。优先补齐整个单基有限区间表达式类的无除法局部运输和端点处理；双基、更多独立基各自建立契约。验收应含变量改名、移动上下界、端点为零、形式证书分母可去与不可去等结构变体。

### 4.2 `recurrence`：递推构造与唯一性

**数学范围。** 有外层离散参数的两侧表达式 S(n)、T(n)，或已定义序列之间的关系。若能有效构造并证明共同线性递推、相同强迫项和足以传播的初始／奇异处数据，就能通过唯一性证明。该思路不要求原表达式本身的相邻项比是有理函数。

**可执行子类必须拆分。**

| 子类 | 准入表示 | 保证应如何表述 |
| --- | --- | --- |
| 单基单重 q-超几何 | 有限和、n 与 k 的相容有理移位商、支撑和原域条件 | 对固定阶数的证书求解与逐阶递推搜索分开；额外满足适用的 proper／q-holonomic 条件时才引用相应存在性结论 |
| 单基多重 q-超几何 | 固定有限个求和指标、全部方向的相容移位、有限域及各边界面 | 构造向量通量；多变量有理比值本身不是本项目有界搜索完备性的证明 |
| 已知 q-holonomic／有限秩系统 | 已认证湮灭关系、移位作用与相容性、求和闭包所需支撑 | 在具体模块与闭包定理假设下构造；不能只凭函数名称贴 q-holonomic 标签 |
| 多基或混合移位 | 基关系、各自幂变量和明确差分代数 | 采用对应算法；不能直接套单基 q-Zeilberger 的保证 |
| 非超几何但已知递推的序列 | 从定义证明的递推、有效初始数据、可处理的目标闭包 | 用 Ore 消元／闭包，不要求原序列的一阶比值有理 |

单基 q-holonomic 的多变量定义和有限支撑求和闭包有严格条件；参见 [Garoufalidis–Lê，§3、§5.3](https://arxiv.org/html/1601.07487v2)。这些理论支持多重递推路线，不证明当前代码覆盖所有该类输入。

**算法与证书。** 构造

\[
\sum_{j=0}^r a_j(n)f(n+j,\mathbf k)
=\sum_i\Delta_{k_i}G_i(n,\mathbf k).
\]

求和后保留所有边界通量和移动域修正。两侧可分别求递推，用 Ore 公左倍式同步提升递推及局部证书。已知递推的对象可通过闭包直接得到目标关系。

**原题出口。** 同时证明局部关系、所有边界与移动尾项、强迫项一致、全部所需初始值、递推传播条件。首项系数在原域内可能为零；此时必须分支、补数据或采用其他合法传播关系，不能直接除去。r 个起始值只在相应可传播区间内足够。

**当前实现。** [通用有限和出口](../p1/GENERAL_SUMMATION.md)已含多分量联合伸缩、两侧 Ore 公左倍式和任意正有限阶唯一性规则；不能再描述成“只有一阶或二阶”。结构化 Pochhammer 出口与旧直接 `Finset.sum` 出口仍有差别；一般奇异参数分支尚未完成。[已定义序列出口](../p1/DEFINED_RELATION.md)识别 Rogers–Szegő，包括受限的参数实例闭包；它不是任意函数的递推发现器。

[multisum_pipeline.py](../p1/multisum_pipeline.py)可提取共同单基、指定盒形／单纯形的多重输入；[multisum.py](../p1/multisum.py)使用有界证书搜索。[multisum_lean.py](../p1/multisum_lean.py)仍明确限二维单纯形、一阶首一递推及指定乘积核。更一般有限维符号构造不能计作更一般完整证明。现有 [q-holonomic 核心说明](../p1/QGOSPER.md)还包含两个相容可逆移位的有限秩核心；它不是任意多指标 Ore 理想前端。

**排除与下一改进单位。** 下一单位应是“指定单基有限区间和及其有限线性组合的完整递推出口”，明确长度、参数移动、首项非零或奇异分支策略；随后独立扩大多重边界域和独立多基域。验收按阶数、求和维数、域形状、参数移动、奇异点组合，不按题号添加闭式。

### 4.3 `coefficient`：系数、卷积与基展开

**数学范围。** 多项式、形式幂级数或其他已认证基中的等式，及能够证明等价于某个系数的有限和。形式幂级数中取固定系数的卷积必须局部有限；普通无限和不能无条件交换。q 可以是系数参数，不要求移位商有理。

**可执行子类。** 指定表达式语法的加法、乘法、有限乘积与系数提取；每个原子提供定义或系数规则。若要处理逆幂级数，应另给常数项可逆及相应系数算法。多变量需指定多指标及局部有限性。

**算法与保证。** 用线性性、Cauchy 卷积和基展开产生系数目标，再在声明的系数代数内作精确正规化。有限多项式环正规化可判定对应形式多项式相等；未知函数原子之间的真实关系、剩余非平凡求和不因此获得求解算法。

**原题出口。** 证明原对象到系数表示的桥、有限重排及每项系数相等；若目标是整个级数，使用系数外延性覆盖所有次数，不能只检验有限样本。

**当前实现。** [p2/run.py](../p2/run.py)展开指定的 `fineA`、`fineC`、`eulerProductSeries` 等定义，尝试 1–4 层有限和同余，剩余表达式用精确多项式正规形及 Lean `ring` 验证。逆式按原子保留，不能私自使用 a/a=1。现有深度上限和定义词表是实现限制。

**排除与下一改进单位。** 不承诺任意生成函数发现或自动解决所有卷积余式。改进单位是完整的“系数表达式语法＋系数规则＋局部有限证明”，再为需要额外证明的系数和明确留下义务或组合接口。验收含三因子卷积、不同括号／索引表示、嵌套系数、不可交换无限求和的拒绝。

### 4.4 `product`：有限乘积与指标等价

**数学范围。** 有限集合上的乘积恒等式，可以通过指标双射／分割、有限因子分解和交换代数关系证明。任意有限重数、多个 q 基本身不是障碍；关键是索引变换和因子关系是否属于指定语法。非交换乘积不能任意重排。

**可执行子类。** 明确有限域与因子；range 上的拼接、首项剥离、剩余类、分块、反射、有限嵌套转置，以及有证明的因子规则。有关单位根的规则必须声明阶数为正和本原性等准确条件。

**算法与保证。** 构造域分解／双射见证，统一因子后做幂与环正规化。固定规则及深度的搜索不保证发现所有有效重排；原子因子正规化也不等于一般含参数乘积闭式发现。

**原题出口。** 验证双射、范围、空积、Nat 截断减法、因子顺序和局部代数；分式版本需要原域非零条件。

**当前实现。** [product/pipeline.py](../product/pipeline.py)要求有有限乘积且没有 `Finset.sum`，域为 range；规则搜索包括零、一、两次变换，之后尝试有限收尾。近期已有首项剥离、独立嵌套转置和本原单位根因子规则，见 [COMPLETION.md](../product/COMPLETION.md)。不能按旧审计把这些仍列为完全缺失。

**排除与下一改进单位。** 不因为右边是乘积就把求和公式分给此类。以“仿射指标映射与有限分割的规范表示”改进整个重排类；独立记录需要新因子恒等式的输入。验收含空区间、参数长度、剩余类、依赖嵌套域拒绝及缺失本原性条件。

### 4.5 `interpolation`：插值、零点与有理函数主部

**数学范围。** 两边能作为某变量上的多项式，具有可证明的次数上界；或为指定域中的有理函数，能完整比较主部与多项式部分。多项式次数可以在数学上依赖参数，但需要符号化的节点及证明机制。

**可执行子类。** 指定变量、系数域、次数界、足够互异的节点与精确节点值。有理分支须指定分母分解域、重极点信息及原式定义域。当前采用 0,…,d 节点时要求 CharZero；一般插值定理的关键是节点互异，不必把 CharZero 说成所有插值方法的必要条件。

**算法与保证。** 次数至多 d 的差多项式在 d+1 个互异节点精确为零即可证明为零。主部算法还须比较多项式部分／无穷远行为；仅留数相同不足够。存在符号节点时，其取值证明也可能成为新的困难，不自动承诺解决。

**原题出口。** 证明多项式表示与次数、节点互异和全部节点关系；清分母及主部重建始终回到原参数域。未经证明的数值采样不算节点证书。

**当前实现。** [algebra.py](../interpolation/algebra.py)在原子中选一个变量，使用固定数值次数界和精确符号节点余式；其他原子独立处理。[pipeline.py](../interpolation/pipeline.py)重建原域分母义务。主部限分裂为线性因子的极点，含重极点与多项式部分；不支持一般不可约高次极点的完整出口。

**排除与下一改进单位。** 当前不承诺符号次数 n 或多变量网格。下一单位是“单变量符号次数＋可统一证明的节点族”；不能用逐个 n 枚举代替。验收包括次数不足、节点碰撞、重极点、多项式部分不匹配和分母缺条件。

### 4.6 `noncommutative`：非交换算子与有限词

**数学范围。** 给定非交换代数、标量作用和生成元关系的算子／词等式。q-交换关系、作用在多项式上的移位与乘法算子属于候选结构；它与递推中的 Ore 算子计算有交集，但目标与出口不同。

**可执行子类。** 有限非交换多项式，允许的作用与关系明确。若要承诺按关系得到正规形，应声明终止且适当完备的改写系统／可用的 Gröbner 基；任意局部关系集本身不提供此保证。符号幂 n 须另接归纳与系数算法。

**算法与保证。** 展开合法作用、保持乘积次序、分配及结合、按已证明关系改写、合并同词。自由非交换多项式正规化与带关系的有界改写分开；不能把后者宣传为一般词问题判定器。

**原题出口。** 核验关系的适用类型、标量中心性／可交换性、真实函数作用和最终词等式；不能默认为普通交换环。

**当前实现。** [noncommutative/pipeline.py](../noncommutative/pipeline.py)展开 `kacX`／`kacM`，使用 Lean 有限词化简、`noncomm_ring` 与 `abel`。准入限明确算术／词语法、显式幂不超过 12；拒绝隐藏求和、符号幂及一般函数应用。

**排除与下一改进单位。** 泛化单位应为固定关系代数的 PBW／词正规形及符号幂归纳模板，而非一条具体算子恒等式。验收须含交换顺序错误、错误 q 因子、非中心标量、符号幂以及已认证关系的改名变体。

### 4.7 `combinatorial`：加权双射与符号反转对合

**数学范围。** 两个已定义有限对象集合的加权计数，或一个有限集合上的有符号加权和。权重可为 q 单项式、多基权重或更一般交换加法结构；是否可计算映射与权重是关键，不要求超几何比值。

**可执行子类。** 输入必须有对象、域、权重的语义表示，并选定可搜索的映射语法，例如区间仿射反射、子集插入／删除、指定元素切换。原算术和到对象计数的表示桥也是输入义务。不能只以“存在某个双射”作为可执行准入条件。

**算法与保证。** 在声明模板内生成映射与逆映射，或对合；证明权重保持／成对抵消。完整有限枚举只对给定具体有限规模有意义，不能宣称因此证明所有符号 n。

**原题出口。** 域闭合、逆关系／单满射、权重、固定点及剩余和。固定点不能仅由 w=−w 自动推出 w=0；需要适用的代数条件或单独证明。非零固定点贡献必须保留。

**当前实现。** [combinatorial/pipeline.py](../combinatorial/pipeline.py)明确列出 range／整数 Icc 反射、powerset 的 0／1 切换、固定基数子集插入删除的几何权重模板；后者已有符号 n 的归纳表示桥。它没有一般分拆／路径双射发现器。

**排除与下一改进单位。** 先按对象类建立表示和统一映射语法，再扩展整类操作。验收包括逆映射失效、权重错一幂、固定点不为零、空集和符号规模；不以新增题号模板充当通用发现。

### 4.8 `difference_ring`：差分环／域中的嵌套和积

**数学范围。** 能嵌入指定差分环／域的有限层嵌套和积及其关系。乘积扩张满足 σ(t)=a·t，和扩张满足 σ(t)=t+b，并要求说明常数、代数依赖与实际序列求值。嵌套和的总项比未必有理，仍可能适用。

**可执行子类。** 明确常数域、基础移位、扩张顺序、关系、可逆性和常数保持检查。独立多基有时可作为多个乘积扩张统一表示，但必须通过相应关系检查；“包含多个基”不自动接收，也不自动排除。

**算法与保证。** 在指定塔内求参数化伸缩或有限阶线性差分方程，推导分母／次数界并求解。完整性相对于输入塔和求解空间，而非所有可能的嵌套和表示。有关 ΠΣ* 条件下的算法见 [Abramov 等，§6](https://arxiv.org/html/2005.04944v2)。

**原题出口。** 证明形式对象到原序列的求值映射、移位交换、定义起点、分母和初值／边界，恢复原参数。差分环非零元不一定是单位，不能任意相除。

**当前实现。** 两层必须区分：[difference_ring/pipeline.py](../difference_ring/pipeline.py)主要提取自然前缀和积／Pochhammer，尝试局部移位和前四个自然指标的不变量；[algebra.py](../difference_ring/algebra.py)对多项式关系作有序约化与乘子验证，未清除的除法会拒绝，这不是一般差分塔求解器。

另一方面，[DIFFERENCE_GENERAL.md](../p1/DIFFERENCE_GENERAL.md)对应的独立核心已具备声明域内的高阶 ΠΣ*、代数数系数、可逆系统及部分周期／有限约化代数适配。常数域限代数数域上的有理函数域等明确情况；一般代数函数常数域、不可规范化塔、奇异系统仍有边界。核心未普遍接回十二方法的原题 Lean 出口，不能把已有核心列为尚未实现，也不能计成现有原题覆盖。

**排除与下一改进单位。** 优先补“声明塔→实际序列”的有证明适配及原域运输，复用已有求解器。验收覆盖冗余扩张、根单位、常数变化、不同定义起点、可去／不可去分母及不受支持的塔。

### 4.9 `kernel_transform`：有限核反演与复合

**数学范围。** 有限线性变换 T_A 的反演、复合、支撑转置，以及能证明等价于这些目标的有限和变换。q 和多个基可出现在核系数中；任意外层规模 n 的闭式核需要额外结构算法。

**可执行子类。** 明确有限索引、矩阵条目、系数域和作用目标；固定具体维数可用精确矩阵算法。符号阶数仅接收另行声明的三角／结构核语法，不从“矩阵可逆”推导通用闭式发现。

**算法与保证。** 由 A 构造逆候选，或由 A、B 构造复合；目标候选只用于最后比较。线性代数在指定精确域内计算，但参数化矩阵的泛型逆不自动覆盖奇异特化。三角支撑转置使用有限求和重排证书。

**原题出口。** 验证 AB=I 或 AB=C、支撑和求和交换、核作用到原目标的运输；分母必须由原假设推出。若改用通分或分支，仍须证明原式。

**当前实现。** [construct.py](../kernel_transform/construct.py)已有独立逆／复合构造，不再只是验证外部现成证书。自动矩阵导出限 `Fin m` 的具体 m=1,…,5；另保留三角支撑规则，见 [自动构造审计](automatic_matrix_construction_20261013.md)。

**排除与下一改进单位。** 不承诺一般符号阶数 q 核反演。后续应选一个可描述的三角核语法，统一生成逆核关系及其证明，而非缓存个别反演公式。验收须区分参数条目与符号阶数，包含奇异特化、支撑外条目和错误逆核。

### 4.10 `spectral`：谱关系与正交

**数学范围。** 有限加权配对中，利用适当自伴算子及不同本征值证明交叉项为零。非对角正交与对角范数是不同任务；本征值相同的情况不能套分离结论。

**可执行子类。** 明确向量／函数族、配对和权重；指定算子搜索语法。当前可采用有限矩阵未知元合成。若用差分算子，应声明阶数、系数语法、边界及离散分部求和条件。双线性配对与复数 Hermitian 配对不可混用。

**算法与保证。** 合成 A 并验证加权自伴及本征关系，再使用本征值差的非零条件。固定矩阵线性方程组可精确求解；并不保证每个正交目标都有指定形式的分离算子，或所得泛型算子可在整个原域解释。

**原题出口。** 自伴关系、本征方程、边界、本征值分离和原目标配对；若要范数值，必须额外构造并证明范数关系与归一化。

**当前实现。** [spectral/construct.py](../spectral/construct.py)对具体 1–5 维向量 f、g、权重 w 解 Af=0、Ag=g、WA=AᵀW，W=diag(w)，再由 0≠1 推出双线性正交。自由算子未知元可置零，输入参数不能当样本特化。没有任意符号阶数的整族算子发现或范数算法。

**排除与下一改进单位。** 应以“有限区间上固定阶差分算子及边界条件”为下一结构类；分别设计交叉正交和范数出口。验收含边界缺失、本征值碰撞、错误权重、双线性／共轭混淆与缺失范数证书。

### 4.11 `determinant`：行列式构造与求值

**数学范围。** 已有有限矩阵表示的行列式恒等式，或有证明可转成行列式的计数／求和。具体维数和符号阶数 n 是不同算法任务；后者须依赖明确矩阵结构或可构造的递推证书。

**可执行子类。** 具体有限阶、精确条目可作一般矩阵计算；符号阶数应分别登记 Vandermonde、三角／块结构、可统一构造的 LU 或行列式递推类。组合式到行列式的桥不能省略。

**算法与保证。** 构造 PLU 并计算对角积，或采用无除法行列式算法；结构化分支构造对应分解。固定阶行列式计算本身是有限算法，但并不决定含未知函数条目的所有真实关系，也不产生任意符号阶数闭式。

**原题出口。** 验证矩阵分解、置换符号和结果；所有主元条件留在原域。泛型 PLU 失效时可尝试无主元除法的重建，不能补入未给定非零假设。

**当前实现。** [determinant/construct.py](../determinant/construct.py)从输入矩阵独立构造 PLU 和 Berkowitz 值，并准备余子式重建计划；自动导出限具体 1–5 阶，另有结构规则。目标行列式值不是构造输入。代码有收尾回退计划，不代表所有构造阶段异常或原域问题均已自动处理。

**排除与下一改进单位。** 下一单位是明确符号阶数矩阵族的统一分解／递推构造及出口，而不是提高具体维数上限后宣称支持任意 n。验收含换行符号、零主元、参数特化、奇异矩阵和符号 n。

### 4.12 `macmahon`：线性整数约束与 Ω 消元

**数学范围。** 固定有限个整数变量的线性等式／不等式约束，加单项式型权重；或已经编码的 Elliott 型有理生成函数，求非负部／常数项，再运输回有限和或系数恒等式。这里“固定有限维”指维数作为输入给定的整数，并非只能一维或二维。

**可执行子类。** 给出约束矩阵、变量符号与范围、权重、参数系数索引和展开语义。核心可接收有限 Laurent 分子及 ∏(1−M_j) 分母，M_j 为有理常数乘整数幂单项式；每个几何因子具有严格正外部分次，以确定形式展开。符号变量个数、非线性指数和任意展开方向不包含在该核心声明中。

**算法与保证。** 编码线性约束，按外部分次区分正负展开，对每个辅助变量作精确分组部分分式与投影。分解见证不仅要有有理函数等式，还要有正负支撑／次数证据。相关方法见 [Xin 的部分分式 Ω 算法](https://arxiv.org/abs/math/0408377)；本项目不是其软件的完整移植。

**原题出口。** 对象到整数点／生成函数的等价、局部有限性、投影合法性、去临时标记及系数运输；有理式相等不能忽略展开约定，投影也不能无条件逐因子分配。

**当前实现。** [macmahon/pipeline.py](../macmahon/pipeline.py)的完整入口以有限 Laurent 投影、链和矩形生成函数模板为主。更广的 [有理 Ω 核心](../macmahon/RATIONAL_OMEGA.md)支持固定有限维和多变量逐次消元；[adapter.py](../macmahon/adapter.py)已有整数仿射区间、指数线性权重的部分有限和适配，保留符号参数为系数索引。该适配和核心的局部回放尚不等于十二入口中的一般 Lean 原题证明。

**排除与下一改进单位。** 先贯通已声明的“有限仿射区间＋指数线性权重”子类：源绑定→编码→消元→系数／另一侧比较→Lean。嵌套超几何项不因有多重求和就自动属于此类。验收含多辅助变量、重因子、展开方向改变、Nat 截断缺支撑、去标记极点和错误系数索引。

## 5. 单重、多重、单基、多基不能省略

此表回答前面讨论中最容易混淆的入口范围问题。

| 输入结构 | 数学上可考虑的路线 | 当前审查结论 |
| --- | --- | --- |
| 单重、单基、超几何项 | Gosper，q-Zeilberger，必要时差分域 | 已有核心和多种完整出口；仍受语法、支撑、原域与预算限制 |
| 多重、单基、相容超几何项 | 多变量创造性伸缩／符合假设的 q-holonomic 求和 | 不是理论上必须交给别的方法；现有多重 Lean 出口较窄 |
| 单重、独立双基或更多基 | 对应多基 Gosper／差分域／创造性伸缩 | 受限双基直接伸缩存在；不能宣称一般多基递推已接通 |
| 多重、独立多基 | 同时处理多个方向和多个基的差分代数 | 没有通用完整入口承诺；单重双基与多重单基能力不能直接相乘 |
| q、q² 等相关基 | 先认证基关系，再在合适的共同移位模型中表示 | 关系归一化可能降低独立基数，但不会自动解决所有表达式适配 |
| 非超几何、已知有限阶递推 | 递推唯一性、Ore 闭包，或差分环 | 递推数学范围包括此类；已有对象识别和原题出口仍有限 |
| 有限仿射整数点、单项式权重 | Ω／系数／组合，有时也可递推 | 方法交集真实存在；必须分别满足各入口契约 |

“q 是形式不定元”与“q 可特化为 0、1 或根单位”也要分开。形式域中的独立性、分母和轨道性质不自动运输到所有特化值；能否覆盖这些值取决于原声明和额外的证明运输。

## 6. 与 Train 四家族的关系、交集和覆盖缺口

四家族依据 [families.json](../../benchmark/metadata/families.json)组织输入数学结构，十二方法组织证明机制；两者是多对多关系。下面只列结构上候选，不是已测可解性标签。

| Train 家族 | 结构候选方法 | 不能据此推断 |
| --- | --- | --- |
| A：超几何型有限求和 | 望远镜、递推；有相应表示时也可系数、差分环、核、谱、插值等 | 所有 A 都是单重单基；或所有 A 都能由当前 q-Zeilberger 证明 |
| C：递推与差分关系 | 递推、差分环；特定算子／代数表示可能适用其他方法 | 所有 C 自动 q-holonomic，或写着递推就已知其证明 |
| F：有限乘积与局部代数 | 乘积、插值；带参数移位等结构时也可递推／差分环 | 和式右边是乘积就应归 F／交给乘积入口 |
| G：合并的其余结构 | 系数、插值、核、谱、行列式、Ω、组合、差分环等 | G 是单一算法域，或某一个方法负责兜底 |

重要交集有：递推与差分环共享移位方程；Ω 与系数法共享生成函数及系数运输；核与行列式共享矩阵代数；组合与乘积／系数共享有限对象表示。共享数学引理和转换层可以复用，但不得把同一个未闭合义务在方法间转交后就记作已解决。

目前最明确的缺口是：

1. **转换与原域缺口**：标准符号核心已支持，原式的长度、支撑、分母、参数特化不能完整认证。
2. **多重边界缺口**：多维符号证书与有限域边界面之间的 Lean 出口不足。
3. **独立多基缺口**：一般递推的多基表示、核心保证和完整出口没有统一契约与实现。
4. **符号规模缺口**：具体次数／矩阵维数算法不能代替任意 n 的结构证明。
5. **构造发现缺口**：双射、谱算子、结构核、符号阶数分解仍限特定构造语法。
6. **强核心接入缺口**：ΠΣ 与有理 Ω 的已有核心能力没有全面反映在十二入口的完整证明能力上。

一个方法不支持，**不意味着其他方法已经接管**。选择器只能按独立准入与证据选择候选；评分高也不等于入口已支持。本文没有改变现有 AHP/TOPSIS 评分或未知并列执行策略。

## 7. 按范围推进的开发与验收规则

每次开发以一个完整结构子类为单位，按以下顺序记录：

1. 写出有限输入语法、系数域、基关系、指标和支撑条件，并给出结构性准入检查。
2. 声明所求证书类，以及完整算法／有界搜索／模板搜索的确切保证。
3. 打通原式转换、核心构造、原域和边界初值处理、Lean 原声明验证。
