## 数学输入和输出

基域为 `F=K(X)`，`K=QQ(q,其他独立参数)`，`σ(X)=qX`，`σ(K)=K`。
q 是不定元，特征为零。接收：

- 乘积块：`σ(P_i)=b_i P_i`，非零 `b_i∈F`。算法检查它们模有理乘法差分的独立性；
  不要求调用者提供独立性假设。
- 和塔：`σ(S_i)=S_i+a_i`，`a_i` 是前面乘积的 Laurent 多项式及前面和变量的多项式，
  系数可为任意基域有理函数。没有固定的“一层／两层”限制，层数受资源预算控制。
- 非空右端基 `f_1,...,f_m`，属于同一环。

构造全部 `(c_1,...,c_m,g)` 的常数域向量空间基，满足

```text
σ(g) - g = c_1 f_1 + ... + c_m f_m,     σ(c_i)=c_i.
```

保留 `c=0` 的齐次方向；选择一个 `c≠0` 的向量归一化后输出 `constructed`。
如果只有齐次方向，返回 `no_relation_in_declared_basis`。这只是当前表示和常数域内
不存在所求参数化关系，不能解释为原恒等式不可证明。

各层移位关系是输入数学模型的前提。原有限和／积如何映射到这些变量、起点和初值、
参数特化的分母非零条件，需要后续转换及验证层处理。公共接口始终给出
`original_identity_proved=false`。

## 算法链与界

### 1. 乘积扩张合法性和依赖

对每个 `b_i` 在 `K[X]` 分解，记录 X 的赋值，并用已有 q-Gosper 的精确
`dispersion` 计算非零不可约因子的 q 移位轨道；没有固定偏移枚举半径。
将同轨道因子转移到共同代表，得到

```text
b_i = (σ(h_i)/h_i) · u_i · X^v_i · ∏ p_j^e_ij.
```

`h_i` 是计算出来的有理见证。继续把 `u_i∈K*` 分解成有理素数和参数多项式因子。
只忽略 `±q^z`：q 幂是 `σ(X^z)/X^z`，负号在平方后消失。各个赋值构成整数矩阵。

- 矩阵满列秩意味着不存在非零整数指数向量，使这些乘积比的某个幂成为有理乘法差分；
  因此逐个加入的是保持常数域的 Π 扩张。
- 有核时，自动求整数指数 `e_i` 和 `h`，并精确核验
  `∏ b_i^e_i=σ(h)/h`；必要时平方以处理符号。
- 若新变量指数为 1，可计算 `P_new=C·h·∏P_old^(-e_old)`，引入自由非零常数 C。
  例如比值为 2 和 4 的两个变量得到 `P_2=C·P_1²`。
- 若需要代数常数或根单位环，例如依次给比值 4、2，或给比值 -1，则输出具体依赖见证，
  返回 `unsupported_domain`，不虚构 Π 独立性。后续可增建代数／根单位模块。

### 2. 和扩张合法性及常数处理

加入 `σ(S)=S+a` 前，在前一层调用本核心求 `σ(g)-g=c a` 的完整解空间。

- 存在 `c≠0`：先除以 c 得原函数 g，记录 `S=g+C` 和 `C=S-g`。
- 不存在：记录无原函数的判定基，接受保持常数域的 Σ* 扩张。

**不将 C 自动设为 0。** 比如 `σ(H)=H+X`，只能得到 `H=X/(q-1)+C`。
如果输入仅要求求 H 的原函数而塔中没有步进变量 `σ(N)=N+1`，一般常数 C 的
原函数并不在基域内，因此不能把 `X/(q-1)²` 错当作 H 的原函数。

引入的自由常数使模型保持与原形式塔的可逆变量联系；它不是已求出具体序列初值。
后续常数定义可以依赖前面的常数，输出时逐层恢复，不捕获用户同名参数。

### 3. 多项式和塔逐层下降

设最高层为 `σ(S)=S+a`，右端关于 S 的最大次数为 d。
非零原函数的次数至多为 **d+1**，这是推导界，不是用户给定的搜索次数。
若 `deg(g)=D>d+1`，最高项系数须为常数；再比较 D-1 次系数就会得到
前一层中 a 的原函数，与 Σ* 条件矛盾。

从 d+1 次开始下降，每一步在前一层解参数化差分方程，保留完整参数空间及齐次方向，
再将其代回下一次系数方程。所有右端共用同一组参数，不能分别挑选独立证书后拼接。
每一层结束后回代该层原始方程，检查残差严格为零。

### 4. 乘积 Laurent 支持和有理基域

独立乘积的不同指数模式在移位下不混合。对指数向量 e，其系数方程为

```text
(∏ b_i^e_i) · σ(r_e) - r_e = Σ c_j [P^e] f_j.
```

只需右端出现的指数及零指数。若其他非零指数存在齐次解，就会给出乘积依赖，
与前面 Π 合法性检查矛盾。因此无需猜测正负指数窗口。
零指数先处理，保留常数齐次方向，即使所有右端参数随后被消去，也不会丢失这个解。

每个系数方程调用第三阶段 `qrational_system.solve_system` 的一维情况，
复用通用分母界、Laurent 次数界和完整零空间。各指数模式依次约束同一参数空间。

对本阶段接收的 Laurent／多项式右端，若原函数在所声明 ΠΣ* 分式域中存在，
其扩张变量分母也不会带来额外解：分母的有限移位轨道必须含特殊因子；Σ* 中没有
非常数特殊多项式，Π 中只可能是已允许取逆的乘积变量。沿塔逐层可约化到上述环。
这也支撑和扩张检查中的“前一层没有原函数”判定。
此结论不表示本实现接收任意右端分母；例如 `1/S`、`1/(1+P)` 仍明确拒绝。

### 5. 原变量回代和资源

输出不仅检查规范化塔的证书，还把每个新常数还原为原变量表达式，直接验证输入移位下的
`σ(g)-g-Σc_i f_i=0` 以及 `σ(c_i)-c_i=0`。完整解空间基和选中的证书都执行此检查。
这仍是 SymPy 精确符号检查，尚不是 Lean 形式化证明。

公共进程硬超时覆盖因式分解、轨道构造及线性代数。
`max_states` 约束扩张数和乘积支持数，`max_unknowns` 约束有理线性系统及参数空间，
`max_normal_form_degree` 约束派生次数及乘积轨道见证大小。
超预算只返回 `resource_exhausted`，不返回无解。

## 公共接口与例子

只允许根字段 `schema_version,solver,input`。
`input` 只允许 `extensions,rhs_basis`；表达式沿用整数／符号／算术树，不执行表达式代码，
不接收目标、猜测分母、猜测次数或已有证书。

以下输入描述 `σ(H)=H+1/(1-X)`，共同求解两个右端的线性组合：

```json
{
  "schema_version": 1,
  "solver": "difference_ring",
  "input": {
    "extensions": [
      {"kind": "sum", "name": "H", "increment": ["div", 1, ["sub", 1, "X"]]}
    ],
    "rhs_basis": [
      ["div", ["mul", 2, "H"], ["sub", 1, "X"]],
      ["pow", ["sub", 1, "X"], -2]
    ]
  }
}
```

程序自动得到 `c=(1,1), g=H²`，另有齐次基向量 `(0,0,1)`。

```bash
# 在 finite_product_framework 目录中运行
python3 solve_core.py --input p1/examples/core_difference_single.json --output /tmp/difference.json --seconds 60
python3 -m unittest discover -s p1 -p test_difference_core.py -v
```

其他持久化输入见 `p1/examples/core_difference_*.json`，对应输出及测试统计见
[本阶段验收](../generated/difference_core_20261014/validation.json)。例子包括嵌套和、
乘积混合和、冗余扩张、无关系及不支持域；不是从 Train 中挑选题目。

## 参考与实现范围

常数域判据和多项式系数逐层下降参照 Abramov、Bronstein、Petkovšek、Schneider 的
[ΠΣ* 差分方程论文](https://arxiv.org/abs/2005.04944)，尤其 Theorem 3 与 §5 的系数下降。
本项目在上述特定环上实现了参数化求和；乘积轨道整数矩阵、递归参数空间管理和
原变量回代由本地代码完成，没有安装或调用外部 Sigma。
[Sigma 官方介绍](https://www1.risc.jku.at/sw/sigma/)列出的多重求和、递推求解等更广能力，
不应被视为本项目已经实现的功能。

以下仍需后续扩展，不能写成“第四阶段已实现通用 Sigma/Karr”：一般扩张变量分母的
轨道／分母算法，和积任意交错及依赖和变量的乘积，代数常数和根单位差分环，
一般高阶 ΠΣ 差分方程、深度最优求和、原题表达式转换及 Lean 闭合。
