# P1 完整证明流程规格

后续分支的[方法拆分、train候选索引与端到端设计](branches/remaining_methods.md)已单列。其后，[一般 q-Zeilberger](branches/general_q_zeilberger.md)已实现联合搜索及受限一/二阶端到端出口，新增 Gauss 交错 Gaussian 原题；[双基 Gosper](branches/bibasic_gosper.md)已接通双基原差分搜索和有限区间端点出口，新增GR2-II-34。[Ore 闭包与消元](branches/ore_closure.md)随后接通定义递推、二次闭包及加权有限和出口，新增GR2-7.Ex40。其余分支仍为设计。

P1 的共享模块负责语义一致性和证明组装；各分支负责适用性判断与完整数学构造。模块按需要调用：直接求值可以绕过递推、初值和唯一性。当前规格仅面向 train，不更改原目标或增加目标没有的假设。

## 禁止题目预设的统一约束

此约束适用于P1总框架和全部分支：不得按题目ID选择预写证书、移位比、递推、边界、初值、局部引理或最终证明。仅允许通用数学定义、算法、搜索资源限制和共享定理。具体构造必须从输入推导并记录来源，预算不能针对已知答案暗设。

无法自动完成的节点必须保留为缺口；禁止调用人工题目证明补齐后标记proved。结构化公式转录只有在证明与原Lean语义一致后才可进入目标证明覆盖。当前自动训练证明数为11，统一验收见 validation.json，旧专用试点已归档停用。

## 输入与语义

输入记录包含 identity_id、训练清单定位、原文件及 SHA256、Lean 完整声明的上下文、类型和类型类、参数和假设、所用定义及哈希、目标表达式。不能只解析网页公式或截取 theorem 的等式部分。

当前受限语法的 Lean 前端在隔离环境中 elaboration 原声明，将 Expr 与定义依赖导出；具体范围见 README。不得 import 原题中含 sorry 的 statement 后用它证明自己；只能导入经审核的共享定义和引理。

符号表示需区分 Nat/Int 指标、自然数截断减法、整数与自然数幂、range/Icc、Gaussian 多项式与商表示、分段项和零延拓。每次重写产生带作用域的等价证明义务。CAS 中的分式化不改变原 Lean 目标的参数域。

## 共享阶段

|阶段|输入与工作|输出与通过条件|
|---|---|---|
|读取目标|声明、定义、假设；检查 train 身份|不可变目标快照；完整上下文|
|表示转换|有限支撑、移位变量、底数、求和维数；生成转换义务|符号表达式及向原语义的桥接任务|
|适用性判断|分支专属前置条件、实际移位关系、搜索限制|可试分支；条件不足需明确记录|
|分支构造|原差分、参数关系、算子或递推系统|局部关系、所用条件、搜索日志、预期证明步骤|
|局部验证|验证关系本身及其定义域|对应的 Lean 引理；CAS 化简不能代替此步骤|
|有限求和|统一移位后的支撑，计算端点与新增删除项|真实求值式或含修正项的递推|
|闭合目标|端点比较，或目标递推、初值、推进条件|两端相等；无遗留义务|
|Lean 输出|组合引理，恢复原表示与声明上下文|完整原目标证明源码|
|验收|编译、类型核对、目标依赖的公理审核|同一目标，无 sorryAx 或额外假设|

设计要求阶段产物作为带依赖的证明图保存；当前实现保存阶段列表、构造日志、证明源码和编译审计，完整节点化证明图尚未实现。每个节点至少有 id、kind、命题/表达式、假设作用域、依赖节点、来源、状态、Lean 定理定位。只有依赖全部闭合的节点才可记为 verified。

## 分支接口

每个分支实现 `analyze(problem)`、`construct(problem, limits)`、`obligations(construction)` 和 `emit(verified_nodes)`。这些是拟议通用接口。当前 run.py 已接通原声明提取、q Gosper构造和受限语法的完整证明生成；lean_pipeline.py 直接验证原语义。现有目标引导、直接 q-Gosper 与一般 q-Zeilberger 分支按结构路由；统一插件式注册和任意表达式的证明生成仍未实现。

`analyze` 返回适用、不适用或条件待证；`construct` 返回结构化证明计划及工具原始输入输出，不能仅返回 true。计划包含局部关系、端点、目标比较、初值或直接求值步骤。工具超时与搜索范围内未找到分别记录。

|分支|构造与证明出口|独立前置条件|
|---|---|---|
|直接已知差分|展开定义，有限望远镜，比较端点|可证明的局部差分；允许任意函数|
|q Gosper|原差分构造，局部验证，端点求值|可处理的单基超几何表示及原差分类|
|目标引导一阶关系|目标递推引导局部搜索，有限求和，初值归纳|目标有适当相邻关系；局部搜索可成功|
|一般 q Zeilberger|搜索高阶递推，处理边界，目标比较与唯一性|相应算法要求的表示；阶数与搜索界显式记录|
|多指标求和|多移位构造或逐方向望远镜，边界面求和，递推闭合|固定维数与可处理支撑；不自动覆盖任意维数|
|双基与多基|专用差分表示与构造，求值或递推闭合|独立底数的表示与后端能力分别核查|
|差分域与差分环|嵌套和积表示，望远镜或递推求解，回译与目标比较|扩张合法性、常数条件、表示桥接|
|算子方法|闭包与消去，求和边界，公共递推与唯一性|已证算子描述及适当消去条件|
|Abel 组合|分部求和与原差分组合，再端点或递推闭合|分解与组合关系本身需证明|

qZeil、qMultiSum、pqTelescope、Sigma、HolonomicFunctions 是相应分支的候选工具入口，不是已接通能力。T/R 是两端递推来源和比较的组织方式；它们可调用不同构造分支。不同分支不承诺互斥或完备。

## 边界与唯一性

若在共同区间有 Σ_j c_j(n)F(n+j,k)=G(n,k+1)−G(n,k)，对共同区间求和后还需恢复每个 F(n+j,k) 原本的求和域。端点差与增删项共同组成 B(n)，得到 Σ_j c_j(n)S(n+j)=B(n)。不能假定自然边界必为零。

若比较两端，须证明同一个递推与同一个非齐次项，或证明二者导出同一齐次关系。高阶推进要求最高移位项系数在相应域非零，并给足初值；若有奇点或步长大于一，则拆分有效区间/余数类并提供连接证据。

首版共享引理实现 range(n+1)、步长一、最高系数为 1 的一阶递推。新增higher_order_unique支持任意正阶monic递推及非齐次项；telescoper_sum在最大有限支撑上求和并保留端点。低阶系数可以为零；不能把它们非零或目标值非零作为额外前提。具体自动回译目前为受限一/二阶，不因共享引理泛阶就宣称高阶目标全自动。

## 状态与失败语义

`planned` → `represented` → `applicable` → `constructed` → `local_verified` → `assembled` → `proved`。

任何阶段均可返回 `unsupported_structure`、`representation_gap`、`backend_unavailable`、`search_exhausted`、`timeout`、`boundary_unresolved`、`domain_unresolved`、`initial_values_unresolved` 或 `lean_failed`，同时记录失败节点及已完成产物。搜索失败不表示数学上不可证明。

`proved` 要求原目标类型核对通过，整个证明依赖不含 sorryAx，不添加假设、不改定义、不复用待证题本身。Lean 标准逻辑公理如 propext、Classical.choice、Quot.sound 可记录而不误报为占位。

## 验收层次

规格完成、共享引理通过、CAS 构造通过、单条完整证明通过、分支复用通过分别计数。只有最后两类涉及训练目标覆盖。

后续目标仍包括：有限 q 二项式原目标回归；含显式分母的另一训练目标；目标零值和不可用一阶关系的正确路由。有限数值抽样和固定 n 展开仅作诊断，不能替代任意 n 的 Lean 证明。
