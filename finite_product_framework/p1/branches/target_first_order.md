# 目标引导的一阶递推分支

本分支输入原目标的求和项 F 和右端 T。具体递推与证书必须由输入计算，不接收题目专用构造提示，不调用按题目 ID 索引的证明。

## 构造步骤

1. 从 Lean 声明提取参数、假设、求和域、F 和 T，证明符号表示与原定义一致。当前由 Lean Expr 导出并在最终证明中通过 `change` 及原定义上的局部验证完成；结构化公式输入仍只用于符号实验。
2. 通过通用有限乘积和移位规则计算 U=F(n+1,k)/F(n,k)、V=F(n,k+1)/F(n,k)、c=T(n+1)/T(n)。这些商首先属于形式有理函数域，不能据此给原题增加非零条件。
3. 搜索 R，使 V(X)R(qX)−R(X)=U(X)−c，令 G=RF。分母、次数和变换都必须具有来自方程或通用算法的来源记录。
4. 将搜索结果回译为原参数域上的局部差分，并自动生成 Lean 证明。不得由人工补写该题的 G 定义或局部引理；无法回译则报告表示/参数域缺口。
5. 根据实际求和支撑生成边界修正，验证目标同递推、初值和推进条件。不得预填边界为零或提供该题预写的尾项抵消证明。
6. 用共享引理组装并检查原 Lean 目标；只有全部闭合才标为 proved。

直接求值、步长变化或一般阶递推需要相应分支处理，不能通过加强目标假设强行进入一阶分支。

## 当前后端

分支使用 q Gosper 算法求目标相邻差D的原差分。qgosper.py实现形式有理系数域上的精确移位集合、正规化、Laurent次数界与系数方程求解；search.py负责q WZ调用及恢复证书。算法、适用域与来源见[详细说明](../QGOSPER.md)。

分母不作为输入，次数范围不由预算枚举。算法计算出完整Laurent区间后，若方程无解，可在对应形式域和q超几何原差分类内报告无原差分。超时或未知数数量超出资源限制须分别报告，不能视为数学无解。主流程不再调用旧有界有理搜索。

## 输入约束

结构化输入只允许 schema_version、source_id、summand、target 四个字段。公式为白名单算术树，支持整数、参数、加减乘除、幂、poch 和 gaussian；不使用 eval。证书、候选分母、次数答案、递推式和 Lean 证明字段均被拒绝。

source_id 仅核对 train 身份，不影响转换或搜索。结构化公式尚无从原 Lean 类型导出的证明，故找到证书也只能标记 constructed_not_proved。

## 验收状态

已验证自动移位、输入变化后的响应、q Gosper正规化、Laurent次数界、有理残差、资源耗尽、拒绝构造提示，以及原 Lean 输入不回退到旧预设证明。

受限语法的 Lean Expr 前端、证书回译、局部/边界/初值/目标递推生成与最终输出已接通，本分支自动训练证明数为1。另有两个合成变体通过，篡改证书被 Lean 拒绝，均不增加 train 覆盖。当前限 range(n+1)、Gaussian 权重、单个 Pochhammer 目标，以及能转为多项式乘原项或向后移位一项的证书；其他分母和支撑、奇偶及高阶递推尚未接通。边界修正零来自目标的齐次递推要求，必须经 Lean 实证尾项抵消，不能视为已知边界值。

原有限 q 二项式人工局部引理已退出运行路径，仅留在历史档案，不能用于补齐自动流程缺口。
