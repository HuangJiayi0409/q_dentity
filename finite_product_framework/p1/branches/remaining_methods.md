## 1. 方法应按什么层次拆分

P1 是差分、望远镜与递推的主机制名称。不要把下一分支命名为 P2：项目中的 P2 已表示有限展开、系数比较与卷积归约。

|拟议分支/模块|对应旧标签|性质与新增能力|
|---|---|---|
|`zeilberger`|Z|联合求递推系数与证书；递推阶数、步长不由目标相邻比预先固定|
|`reduction_ct`|Z 的可替换后端|通过约化余项的线性相关求递推，复用同一证明出口|
|`ore`|H；服务 T/R|从已证算子关系做闭包、消去、公共左倍数；允许非单个超几何项|
|`multisum`|M|固定多指标移位关系、多方向证书或逐层消去|
|`bibasic`|B|独立两底数上的原差分搜索；不能直接用现有单变量 q-Gosper|
|`difference_ring`|补充 X/H 的部分任务|嵌套和积的参数化望远镜及递推求解，须核对扩张条件|
|`abel`|AL|组合已证局部差分；它是组合策略，不是通用原差分搜索器|
|`direct_difference`|A；部分 X|从显式差分/候选累积乘积直接验证并求和；不要求项比超几何|
|`compare_sums`、`compare_defined`|T、R|递推来源与比较的组织层，调用上述构造器；不重复计作底层算法|

这是一组可实施路线，不是“全部符号计算方法”的完备分类。参数 contiguous relations 可由参数化望远镜或 Ore 分支生成；递推猜测只能提出候选，仍须生成一般证书或从定义验证；不另建一个“抽样即证明”的分支。

## 3. 所有分支共用的证明接口

端到端定义：原 Lean 声明 → 经验证的表示转换 → 构造局部关系/对象递推 → 验证原域 → 对实际支撑求和 → 比较目标与初值 → 原目标 Lean 编译、公理审计。仅得到 CAS 递推不算端到端完成。

建议逐步实现以下公共产物，避免先重写现有 P1：

```text
ProblemSnapshot: 原目标/假设/定义/hash/train定位
Representation: 指标类型、支撑、底数关系、表示等价义务
LocalRelation: 算子、通量或多移位关系、系数域、适用区间
BoundaryPlan: 共同支撑、移动支撑增删项、真实端点/边界面
Recurrence: 移位集合、系数、非齐次项、有效域
ClosurePlan: 目标递推或直接端点、初值、推进/奇点证明
ProofArtifact: 原目标证明、依赖、公理、未闭合节点
```

`analyze → construct → obligations → emit` 沿用主规格，仍为拟议接口。每个构造产物记录算法版本、搜索空间、资源限制和输入哈希；不按 identity_id 注入证书、递推或初值答案。

特别要先补共享的高阶闭合器。设

\[
\sum_{j=0}^r a_j(n)S(n+j)=B(n).
\]

左右须有同一个算子、同一个 B 和足够初值。若 a_r=1，可直接强归纳；否则须在每个推进点证明 a_r 非零。系数为零时不能继续相除：可换算子、求额外关系、分域并提供新起始值，或证明多项式身份后合法特化。步长 d 的递推须覆盖各剩余类。原假设只保证到 n 的分母时，要显式说明如何合法取得涉及 n+r 的实例，不能默认条件在移位后保持。

## 4. `zeilberger`：联合递推—证书构造

**核心方法。** 令 Q=q^n、X=q^k，从输入推导 U=F(n,k+1)/F(n,k) 与 V_j=F(n+j,k)/F(n,k)，联合求不全为零的 c_j(Q) 与 R(Q,X)：

\[
\sum_{j=0}^r c_j(Q)V_j(Q,X)
=U(Q,X)R(Q,qX)-R(Q,X).
\]

乘回 F 得到通量 G=RF 的局部关系。r 从小到大搜索，也允许稀疏移位集合；不是先猜定数值 c_j 后反复运行现有 q-Gosper。参数化 Gosper 的正规形、次数界、线性求解需专门实现。q-超几何项比有理本身不保证算法必成功；存在性条件与预算分开记录。[qZeil 官方说明](https://risc.jku.at/sw/qzeil/)

**完整链。** 原式提取 → 单基移位比/平衡约束 → 参数化 Gosper → 局部身份独立复核 → 证书在原表达式中的无非法除法回译 → 共同区间求和及移动端点 → 目标满足同递推 → 初值/唯一性 → Lean 原目标。

**适用域与义务。** 支持的超几何单和；平衡参数先消元或选保持约束的移位。F=0 处不使用数值项比；要验证乘回后的原语义。边界 B 不预设为零。最高系数、目标零值、q=0/单位根按原声明处理。

**CAS 接口。** 现有 SymPy 精确运算与 q-Gosper 正规形可复用；新增参数化线性方程求解。qZeil 可作独立候选后端，尚未部署。**Lean 出口。** 泛阶有限求和与递推唯一性引理，加原语义局部证明生成。

**首个验收对象。** `FQI-GAUSS-ALTERNATING`：目标含奇偶零值，适合检验步长二/二阶递推及两个初值。不得把已知递推预填进搜索器。验收还须包括改名、改权重、错误证书、错误奇支目标及 q 特殊值。

## 5. `reduction_ct`：以约化求递推

**核心方法。** 对 n 移位后的项作统一约化，分解为 k 差分加余项；在合法共同余项空间内寻找移位余项的线性相关，由各次约化恢复证书。它改变 Z 的搜索内核，保持上一节的边界与递推出口。[统一约化论文](https://arxiv.org/abs/2501.03837)

**完整链。** 输入/项比 → 核与壳分解 → 有理及多项式约化 → 兼容余项空间 → 线性相关 → 恢复通量 → 原域局部验证 → 实际边界 → 同递推/初值 → 原目标。

**适用条件。** 论文所覆盖的 shift/q-shift 超几何表示及约化条件，不能把普通 Hermite reduction 直接当作 q 版本。**剩余义务。** 约化实现、余项规范、证书恢复与原域桥接均未实现；先在与 Z 相同的 train 候选上比较。**CAS 接入点。** 精确约化及线性代数。**Lean 验证。** 验最终局部证书即可，不要求先在 Lean 证明约化算法完备性。

## 6. `ore` 与 T/R：算子闭包和递推比较

**核心方法。** 用 E Q=q Q E 的 Ore 算子表示递推。先从定义证明原子对象的湮灭关系，再做和/积闭包或消元。乘积的算子不能用两个算子的普通乘法代替；可先构造张量状态系统再消元。[HolonomicFunctions 官方说明](https://www1.risc.jku.at/sw/holonomicfunctions/)

**T 完整链。** 两侧真实有限和 → 分别调用 Z/M/H → 处理前因子与平衡约束 → 找共同左倍数 L=A L_left=B L_right → 计算两侧被变换的非齐次项 → 证明它们相同 → 全部初值及奇点 → 原目标。若非齐次项不同，不能直接套唯一性；须继续证明差为零或重新构造。

**R 完整链。** 从递归定义或有限和推导对象递推 → 为目标显式表达式构造递推/耦合系统 → 统一算子及有效域 → 初值 → 归纳。保留耦合系统有时比消成高阶标量式更简单。

**适用条件。** 输入对象有已验证且足够的算子描述；名字叫正交多项式并不构成证据。**剩余义务。** 算子作用、乘积闭包、消元见证、前因子零点、公共算子额外奇点。**CAS 接入点。** Ore 精确运算/消元、公共左倍数。**Lean 验证。** 展开有限移位组合，验证每个闭包/消元见证；无需信任 CAS 的“湮灭”标记。

**train 锚点。** R：`FQI-SRC-GR2-7.Ex40` 的 h_n 平方，先从 Gaussian 定义导出 h_n 递推，再导出差积关系及加权累加；T：`FQI-WATSON-8PHI7`、`FQI-SEARS-4PHI3-II`。后两者先作构造试验，不保证比其他变换法容易。

## 7. `multisum`：多指标关系与边界递降

**核心方法。** 固定 d，对多指标核构造有限多移位关系，或构造 L F=Σ_i Δ_{k_i}G_i；逐层消去也是候选。qMultiSum 使用多重 q-Sister Celine 类型技术，后端输出不一定天然就是通量向量，必须保留真实的移位见证。[qMultiSum 官方说明](https://risc.jku.at/sw/qmultisum/)

**完整链。** 展开隐藏和并验证 → 固定维核与真实域 → 各方向项比 → 多移位关系/逐层消去 → 原语义验证 → 域平移差或离散边界面求和 → 将剩余低维边界交给子流程 → 外参数递推 → 目标及初值 → 原目标。

**适用条件。** 后端要求的 proper/支撑条件逐项核查；固定维数算法不证明任意维数或列表长度。**剩余义务。** 三角域、斜边、角点、零延拓与求和换序，边界子流程必须规模递减，避免循环调用。**CAS 接入点。** 多移位线性系统及消元。**Lean 验证。** 验局部关系后用 Finset 双射、差集、不交分解组装。

**train 锚点。** `FQI-SRC-GR2-10.Ex18` 的 j+k≤n 双和；`FQI-SRC-SILLS-4.Mod8` 先展开包装与内部和。首版仅二维；任意 d 的 N 仍是独立外层归纳义务。

## 8. `bibasic` 与多基表示

**核心方法。** 独立 p、q 时用 X=p^k、Y=q^k，σ(X,Y)=(pX,qY)，求 U(X,Y)R(pX,qY)-R(X,Y)=1。这是双变量移位方程，不是对 X、Y 依次运行单基 q-Gosper。[Riese 双基算法论文](https://www.risc.jku.at/publications/download/risc_210/bibasic.pdf)

**完整链。** 底数及关系识别 → 双基正规形/次数问题 → 原差分搜索 → 原乘积通量回译 → 验证局部差分 → 真实端点 → 原目标。右端是累积乘积时可先做下一节的廉价目标引导验证。

**适用条件。** 双基算法规定的形式系数域与可求类；q、q²、q³ 应先按相关基数处理。泛参数证书须在原域验证，不能从形式独立性直接推出所有特化合法。**剩余义务。** 双基正规形、次数界、分母与特殊参数。**CAS 接入点。** 公开算法的独立实现或可获取的后端；论文提到实现不等于本机已安装。**Lean 验证。** 双基有限乘积移位、域内代数、有限望远镜。

**train 锚点。** `FQI-SRC-GR2-II-34`、`FQI-SRC-GR2-II-35`、`FQI-SRC-GR2-3.6.17`。四基或更多基数不据此算覆盖。

## 9. `difference_ring`：嵌套和积与递推求解

**核心方法。** 把乘积和嵌套和分别作为差分扩张生成元，指定 σ(t)=a t 或 σ(s)=s+f；在合法 ΠΣ/RΠΣ 表示中解 σ(g)-g=Σ c_i f_i，必要时解由此得到的递推。周期项/代数乘积可能需要环而不只是域。[Schneider 差分环论文](https://arxiv.org/abs/1408.2776)

**完整链。** 原嵌套和积 → 有序扩张塔与求值映射 → 常数/扩张合法性检查 → 参数化望远镜或递推求解 → 回译为原有限和积 → 验证移位 → 端点/目标递推及初值 → 原目标。

**适用条件。** 每层增量属于前层且表达式可嵌入选定系统；不能因“多基”或“嵌套”外观就认定 Sigma 可直接处理。**剩余义务。** 求值映射、周期生成元、起始索引、极点、原目标对应。**CAS 接入点。** Sigma 类工具或公开算法实现；本轮未安装、调用或指定成功候选。**Lean 验证。** 具体生成元移位及最终证书逐步验证；输出语义正确性与算法搜索完备性分别处理。

此路线待对 train 的嵌套定义逐式建模后再给候选数。先验证几何乘积和单层累积和的表示，再处理真正需要扩张的例子；不把外部文献例子计入 train 成果。

## 10. `abel` 与 `direct_difference`：低成本组合出口

**Abel 核心。** 对 Δv_k=v_{k+1}-v_k，使用

\[
\sum_{k=0}^{N-1}u_k\Delta v_k
=u_Nv_N-u_0v_0-\sum_{k=0}^{N-1}v_{k+1}\Delta u_k.
\]

**完整链。** 从输入/目标结构枚举有资源界的乘积分解 → 调用 G/B 或直接验证得到两组局部差分 → 验 Abel 组合与实际上下限 → 化简端点及转换后的核 → 原目标。适用于能找到合适累积因子的有限变换；CAS 负责局部差分及因子匹配，Lean 用通用分部求和引理组装。分解搜索与全部端点尚待实现。候选为 `FQI-SRC-GR2-3.Ex21-quad`，不得将 K/T/R 的未证关系当定义真理。

**直接差分核心与完整链。** 展开定义或读取目标候选累积积 H → 构造 H(k+1)-H(k) → 验它等于输入项 → 验起点和实际端点 → 有限望远镜 → 原目标。仅在目标/结构提供可枚举候选时使用，不宣称通用求原差分。任意函数 Jackson 式 `FQI-SRC-KAC-CHEUNG-19.telescoping` 不要求 F 的项比；多基 `FQI-SRC-GR2-11.6.6-p0` 可先试目标端点反推。无需外部 CAS，精确代数可辅助。剩余义务是因子非零、索引和端点；Lean 验定义展开与有限求和。

## 11. 实施顺序与完成门槛

1. `zeilberger` + 泛阶/步长递推闭合：以 Gauss 交错式作为首个完整验收；先不追求覆盖全部 Z/T。
2. `compare_sums` / `compare_defined` + 必需的 Ore 运算：先做简单公共递推和 Rogers–Szegő 差积，再扩到复杂双侧变换。
3. `direct_difference` + `bibasic` + `abel`：先验证目标给出的候选累积乘积，再补通用双基搜索。
4. `multisum`：首版固定二维，必须闭合斜边及低维边界。
5. `reduction_ct`：作为 Z 的替代构造后端，与经典搜索对比时间和证书大小；无需另建主流程。
6. `difference_ring`：先完成输入表示实验，再决定哪些 train 条目值得接入。

每条分支达到“已实现”至少要：原 train 声明自动提取；无 ID 专用证明数据；实时构造；原参数域的局部关系、边界、初值全部闭合；Lean 原目标及公理审计通过；改名/结构变体能复用；篡改证书、边界或初值被拒绝。超时、预算耗尽、表示缺口、边界/域/唯一性未闭合分别报告，不记作数学不可证。

本轮只交付方法拆分、与旧映射的可追溯索引及上述端到端设计；没有新增 CAS 后端、共享 Lean 引理或训练证明。完整目录构建/验证与局部索引验证的实际结果见 `remaining_validation.json`。
