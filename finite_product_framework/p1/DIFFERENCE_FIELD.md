## 一般有理 ΠΣ* 算法

求解

```text
A σ(g) + B g = Σ c_i f_i,     σ(c_i)=c_i,
```

其中 A、B、f_i 可以是整个塔中的有理函数。默认 A=1、B=-1 即参数化求和。
输出完整解空间基，包括 c=0 的齐次方向。输入扩张必须三角、移位可逆；新增和／积
都做常数域检查或显式常数归约。涉及未支持代数常数正规化时返回不支持，不能返回无解。

### 精确轨道与乘法正规化

每层按最高变量在前层有理函数域上分解。对首一不可约因子 p、r，计算是否存在
整数 j，使 `monic(σ^j(p))=r`。只在更低层调用辅助求解器，避免同层循环：

- Σ层，`σ(t)=t+β`：由次高系数得到 `d=(r_{m-1}-p_{m-1})/m`。
  若因子相差 j 次移位，则在前层的加法商空间中 `[d]=j[β]`。
  以前层参数化求和求出唯一候选 j，再代回完整因子检查。
- Π层，`σ(t)=αt`：由常数项得到乘法商空间关系
  `[r_0/p_0]=-jm[α]`。前层乘法正规化给出唯一有理候选，必须是整数并通过完整因子检查。

乘法正规化保留因子轨道总赋值及实际乘法差分见证。Π层的前层乘法商空间再模掉 α；
整数矩阵上的有理消元仅用于“某个幂为乘法差分”的判据。实际求 `σ(h)/h=u` 时，
还会检查所需指数是否为整数、符号是否满足，并核验完整有理等式；不把根式当有理函数。

### 分母和次数界

清除 A、B 和所有右端的分母，除去公共内容。在最高层 t 上，将 Π 特殊因子 t
单独保留为 Laurent 指数，其余普通因子按精确轨道处理。
一阶方程中，若 B 的因子移位 j 次后出现在 A，则普通极点链长度至多 j-1。
构造包含全部重数的分母倍式 D；不存在极点链时 D=1。

代入 `g=p/D` 后重新清分母。Π层的上、下指数界来自右端最高／最低次数以及
首尾系数的乘法共振；共振通过前层精确乘法方程判定。

Σ层的次数界不能一律取“右端次数+1”。设清分母后 A、B 同为 m 次，首项 a、b，
若存在前层 u 满足 `σ(u)/u=-b/a=r`，再比较下一系数，得到

```text
σ(z)-z = γ - D β,
γ = (a_{m-1} r + b_{m-1}) / b.
```

通过前层参数化求和确定可能的整数共振次数 D；另保留右端强迫项给出的界。
若首项不能抵消，直接使用次数比较界。所有界均为算法推导；资源限制不是数学搜索半径。

随后从最高次数下降。每次在前层求完整的一阶参数空间，并代入下一系数方程。
剩余低次残差用常数域线性约束消除。每个返回向量都代回原一阶方程检查。

### 乘积换基和周期下降

乘法签名矩阵使用扩展整数 gcd 做列变换，得到行列式 ±1 的整数矩阵 U。
新生成元是原乘积的整数幂单项式，逆变换也只有整数指数。零签名列转成实际自由常数，
有负号扭曲时转入周期算法。所有常数保留定义及原变量回代，不指定原乘积初值。

周期算法先求 σ²，必要时继续加倍，直到得到经过检查的 ΠΣ* 塔。没有固定试探阶数；
超出派生阶数预算只记资源耗尽。求解展开后的参数化关系后，在其解空间上使用

```text
T(c,g) = (σ(c), σ(g)-Σ σ(c_i) f_i).
```

该作用在展开解空间上具有有限阶。选取展开常数域相对不变常数域的原始元，用有限轨道
平均产生不变向量，再用线性独立性选择生成基。最终所有系数和证书都回到原变量中，
逐项检查 `σ(c_i)=c_i` 和原一步差分方程。

## 有限差分环算法

输入三角首一代数关系及生成元移位，或 `root_unity` 声明。程序建立标准单项式基，
用精确多项式约化计算乘法矩阵。对每个分母检查其乘法矩阵可逆；若分母为零因子就拒绝。
检查关系的可分性、移位保持定义理想，以及移位矩阵可逆性。

在有理 q 基域上，用标准基展开 g 和各 c_i，将系数不变性和求和等式一起组成
增广有理矩阵差分系统，复用第三阶段完整求解器。这里未知系数可在整个不变有限代数中，
不只限于输入基域的标量。若选中的系数是非单位，只能报告线性关系，不能除以它隔离某个和。

对自由 ΠΣ* 塔上的常系数有限周期模块，计算矩阵的有限阶，将方程展开到相应步数，
逐坐标用有理 ΠΣ* 核心求解，再施加原一步矩阵方程约束。

如果有限代数可分解成有理分量，就构造分量、移位排列、每个分量的三角正反移位。
沿排列循环组合自由塔移位，求标量参数化关系，再逐分量恢复证书，最后用标准基还原。
这条路径允许和增量及乘积比依赖符号因子，例如 `E²=1, σ(E)=-E`。

## 输入与复现

`difference_field` 仍接收 `extensions,rhs_basis`；可选 `operator:[A,B]`。
无目标答案、预制证书或猜测界。表达式都是原有安全算术树。

```json
{
  "schema_version": 1,
  "solver": "difference_field",
  "input": {
    "extensions": [{"name":"H", "kind":"sum", "increment":1}],
    "rhs_basis": [["sub", ["div",1,"H"], ["div",1,["add","H",1]]]]
  }
}
```

`finite_difference_ring` 接收 `extensions,algebraic_extensions,rhs_basis`。
代数关系是待研究对象的定义，不是求和证书。可直接声明三阶根单位：

```json
{
  "schema_version": 1,
  "solver": "finite_difference_ring",
  "input": {
    "extensions": [],
    "algebraic_extensions": [{"name":"E", "kind":"root_unity", "order":3}],
    "rhs_basis": ["E"]
  }
}
```

程序自动生成原始三阶单位根的圆分关系以及 E³=1、σ(E)=ζE，求出证书。
一般代数定义使用 `name,polynomial,shift` 三个字段。

```bash
# finite_product_framework 目录中
python3 solve_core.py --input p1/examples/core_difference_full_sigma_denominator.json --output /tmp/field.json --seconds 90
python3 solve_core.py --input p1/examples/core_difference_full_root_three.json --output /tmp/root.json --seconds 90
python3 -m unittest discover -s p1 -p test_difference_full.py -v
python3 p1/check_difference_full.py --run
```

测试、CLI状态及源码哈希见 [validation.json](../generated/difference_full_20261014/validation.json)。
成功、范围内无关系、仍不支持的输入分别留有样例。没有调用外部 Sigma，也没有执行 Train 或 Lean。
