## 后续接入：符号上界有限求和适配（2026-10-14）

支持固定有限个嵌套求和变量、整数仿射区间、有限线性组合的指数线性权重。符号自然参数 `n,m,…` 保留为生成函数的系数指标：结果是 `∑ S(n,m,…) C₀ⁿ C₁ᵐ…`，没有把参数代入具体样本值。自然数减法只有在已有区间约束可以给出非负线性证据时才按整数减法编码；其余截断拒绝。非线性指数、整除取整、未知函数、符号维数分拆尚未接通。

每个区间先以 `j=lower+u` 换元，令 `u≥0`；上界变为 `upper-lower-u≥0`。所有约束加入 Ω 辅助变量。原自然参数各有一个正权重系数变量；每个求和变量另乘临时标记 `Grade`，使每个几何因子的外部权重严格为正。消去全部 Ω 变量后再令 `Grade=1`。这一步依据的是：固定所有原参数时，嵌套有限区间只有有限多个整数点。若去标记仍产生不可消除的极点则拒绝。

例如 `∑ k∈range(n+1), z^(n−2k)` 自动生成

`Ω≥ 1/((1-C₀ z L)(1-Grade z⁻²/L))`，

消元及去标记得到 `1/((1-C₀ z)(1-C₀/z))`；其 `C₀ⁿ` 系数对应原求和。这个局部生成函数结果仍需与原题另一侧比较。外部参数按 `W0,W1,…` 重命名，绑定文件记录反向映射与系数指标，不能丢掉这些信息只读有理式。

## 输入与适用范围

输入为

\[
 F(\boldsymbol\lambda,\boldsymbol x)
 =\frac{P(\boldsymbol\lambda,\boldsymbol x)}{\prod_j(1-M_j)}.
\]

- `P` 是有理数系数的有限 Laurent 多项式。
- `M_j` 是非零有理数乘以整数幂单项式，可重复、可有负指数，可有负有理系数。
- 辅助变量数量、分母因子数量、各整数指数均为输入给定的有限数值，没有固定的一维或二维限制。
- 外部变量指定非负整数权重，至少一个权重为正；辅助变量权重为零。要求每个 `M_j` 的外部总权重严格为正。`q` 可以作为权重零的独立参数，实际计数变量如 `x` 权重为一。
- 每个辅助变量指定 `ge`（保留非负指数后令该变量为一）或 `ct`（常数项）。支持混合、逐变量消元。
- 不接受目标答案、用户证书、次数猜测、原题编号或证书候选。

严格正权重规定了 `1/(1-M_j)=∑_{r≥0}M_j^r` 的展开。等价地，把每个外部变量 `x_i` 替换为 `x_i t^{w_i}`，在形式变量 `t` 中展开。每一阶系数只有有限项，其辅助变量指数是整数，因此投影、线性组合和逐变量消元都有明确含义。这不是数值收敛假设。

固定维数整数约束系统的通常生成函数编码属于该类：给每个非负整数未知量一个独立、正权重的计数变量；约束系数作为辅助变量的整数指数。偏移项进入 Laurent 分子。这里接收的是编码后的生成函数；原组合对象与编码之间的证明不在本轮。

## 核心计算

对当前辅助变量 `z`，在其他符号组成的有理函数系数域上处理 `F`。

1. 精确约分并因式分解分母，保留因子重数。每个依赖 `z` 的因子通过外部权重判定展开方向。相对于常数项，其他系数权重均更高的因子归入 `D₊`；相对于最高次项，其他系数权重均更高的因子归入 `D₋`。纯 `z` 因子归入后者。与 `z` 无关的因子进入系数域。
2. 多项式除法得到 `F=P₀+R/(D₊D₋)`。正负组不能有公共非恒定因子。
3. 用扩展欧几里得计算 `U=D₋⁻¹ mod D₊`，再计算
   `A=R·U mod D₊`，`B=(R-A D₋)/D₊`。
   自动得到 `deg(A)<deg(D₊)`、`deg(B)<deg(D₋)`。空组作为分母一处理。
4. 精确检查
   `F=P₀+A/D₊+B/D₋`。
   前两项只含非负 `z` 次幂；最后一项只含严格负次幂。后者的严格性来自分子次数界，不能只检查有理函数相等。
5. `ge` 返回 `(P₀+A/D₊)|z=1`；`ct` 返回 `(P₀+A/D₊)|z=0`。先约分再代入，检查没有未消除的极点或辅助变量，随后处理下一个变量。

没有求代数根，没有对无限级数做有限截断，也没有由样本猜公式。分解次数由实际分母决定，模逆是有限精确算法。把同方向因子放在同一组，避免同组因子之间不必要的部分分式拆分；重因子及非互素几何因子由因式分解和重数自然处理。分解后的圆分多项式可以有三个以上单项式，不能误当成“非二项式就拒绝”。

输入 Elliott 分母及消元产生的二项式结式保持可判定的展开方向。实现对中间因子的方向逐一检查；如果不能认证，会明确返回 `unsupported_domain`，不会按未认证的普通 `apart` 结果继续计算。

算法参考 [Xin, A Fast Algorithm for MacMahon's Partition Analysis (2004)](https://arxiv.org/abs/math/0408377)，尤其部分分式与正部提取的联系。当前采用精确多项式模逆实现两组分解，未声称移植其 Maple 软件，亦未实现 [CTEuclid](https://arxiv.org/abs/1208.6074) 或 [Polyhedral Omega](https://arxiv.org/abs/1501.07773) 的高性能算法。

## 实际构造例子

输入

\[
\Omega_{\lambda\ge0}\frac1{(1-x\lambda^2)(1-y\lambda^{-3})}
\]

得到

\[
\frac{1+x^2y}{(1-x)(1-x^3y^2)}.
\]

这给出 `2a≥3b` 的加权非负整数点生成函数。把同一输入的操作改成 `ct`，结果为 `1/(1-x³y²)`，对应 `2a=3b`。

双辅助变量例子：

\[
\Omega_{L,M\ge0}
\frac1{(1-xL)(1-yM/L)(1-w/M)}
=\frac1{(1-x)(1-xy)(1-xyw)}.
\]

这里运行时实际做两轮代数消元，不依赖旧链求值模板。

## CLI 与输出

在框架目录执行：

```bash
python3 solve_core.py \
  --input p1/examples/core_omega_inequality.json \
  --output /tmp/omega_result.json --seconds 30
```

输入示例：

```json
{
  "schema_version": 1,
  "solver": "rational_omega",
  "input": {
    "numerator": 1,
    "denominator_monomials": [
      ["mul", "x", ["pow", "L", 2]],
      ["mul", "y", ["pow", "L", -3]]
    ],
    "grading": {"x": 1, "y": 1},
    "eliminate": [{"variable": "L", "operator": "ge"}]
  }
}
```

`result.value` 为精确有理结果；`result.steps` 逐步记录输入、因子及展开方向、三部分分式、输出。统一入口保存请求与源文件哈希、预算、版本，`original_identity_proved=false`、`benchmark_files_read=0`。

`max_normal_form_degree` 控制 Laurent 指数和消元多项式次数；`max_states` 控制因子／变量数量；`max_unknowns` 控制展开后项数；`seconds` 由独立进程硬超时实施。因式分解、模逆和约分可能很贵，项数限制不等于内存硬上限；不能承诺高维或大指数输入很快完成。预算耗尽只记 `resource_exhausted`。

回放器重新检查原始输入绑定、因子方向、分解等式、次数与最终投影。篡改检查包含一个仍保持有理函数相等、但破坏负部严格支撑的假见证。这是本地算法验收，不是 Lean 形式化验证层。

本阶段完成范围是上述正权重、固定有限维数的 Elliott 有理 Ω 核心。下列内容不在本轮完成范围：任意有理函数及任意迭代 Laurent 展开序、零权重几何因子的展开选择、符号维数或符号整数指数、原组合对象自动编码、任意参数特化合法性、原题与 Lean 重建。更快的 CTEuclid／锥分解仍是性能扩展方向。算法范围拒绝不能推断某道恒等式在数学上不可证。
